# 🏋️ FitLog - Workout Library

## 📖 Short Description
FitLog is a modern, dark-themed workout library and planner application. It allows users to browse a collection of highly effective gym exercises, view detailed instructions, and build a personalized daily workout plan with calculated metrics.

## 🚀 Live Link
https://fitlog-b14-a6.vercel.app/

## 🛠️ Technologies Used
- Next.js (App Router)
- React
- Tailwind CSS
- React Hot Toast
- React Context API (State Management)

## ✨ 5 Key Features
1. **Interactive Workout Library:** Browse a beautifully designed responsive grid of workout cards fetched dynamically from an API.
2. **Personalized Planning:** Users can add up to 5 exercises to their "Today's Plan" or save them for later in the "Saved" tab.
3. **Live Metrics Dashboard:** Automatically calculates and displays the total number of exercises, minutes, and calories based on the active tab (Plan or Saved).
4. **Dynamic Sorting:** Effortlessly re-sort your workout plan by Duration, Calories, or Rating using a custom styled dropdown.
5. **Seamless User Experience:** Smooth navigation, custom toast notifications, interactive UI elements, and a dedicated 404 error page.
